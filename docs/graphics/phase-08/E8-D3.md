Opremi predmete, otvori radionicu i uporedi dve obrade kratkog maca. Potvrdi jednu i uporedi list lika sa prikazom borbe u 2D i 2.5D.

HTML `Ravan_E8-D3.html`. Snimak E8_D3_Radionica.png i E8_D3_Oprema.png. Snimci koriste pripremljena stanja iste igre. Uz izvorni paket idu detaljni browser i route rezultati.

```sh
(cd /path/to/E8-P5 && python build.py)
python graphics/phase08/build.py /path/to/E8-P5 Ravan_E8-D3.html --through 3
```
