## Kratak test

U kampu pokreni Sumsku stazu. Na mapi procitaj cilj, otvori detalje povratka i kreni prema Sumskom rubu. Sat se menja putovanjem, a otvaranje detalja je informativno.

HTML `Ravan_E8-D4.html`. Snimak E8_D4_Ekspedicija.png. Snimci koriste pripremljena stanja iste igre. Uz izvorni paket idu detaljni browser i route rezultati.

```sh
(cd /path/to/E8-P5 && python build.py)
python graphics/phase08/build.py /path/to/E8-P5 Ravan_E8-D4.html --through 4
```

## Predaja

Graficki kandidat cita stvarni gameplay. P5 integrator objavljuje finalni zajednicki build. Koristi E7 module i novi E8 sloj. Builder menja u izlaznom HTML-u pinovani graficki renderer, battle adapter i audio, pa dodaje E7/E8 stilove i skripte. Gameplay checkout se cita sa diska.

Pre je cilj bio ispod putnih panela, opcioni izazov je bio u stalnom tekstu, a ishod u jednom nizu sa napretkom. Sada je cilj iznad mape, pomoc je sklopiva i ishod ima zaseban prikaz.
