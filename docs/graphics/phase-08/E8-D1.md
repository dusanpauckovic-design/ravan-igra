## Kratak test

U kampu klikni Ognjiste, potvrdi kupovinu, zatim kupi Radionicu. Predji na mapu i vrati se. Posle Nastavi igru proveri da scena pokazuje obe nadogradnje.

HTML `Ravan_E8-D1.html`. Snimak E8_D1_Pocetak.png i E8_D1_Kamp.png. Snimci koriste pripremljena stanja iste igre. Uz izvorni paket idu detaljni browser i route rezultati.

```sh
(cd /path/to/E8-P5 && python build.py)
python graphics/phase08/build.py /path/to/E8-P5 Ravan_E8-D1.html --through 1
```
