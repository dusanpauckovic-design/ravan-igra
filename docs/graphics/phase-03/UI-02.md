# UI-02 — List glavnog lika i saboraca

- List razdvaja zdravlje i statistike, opremu, tehnike i razvoj.
- Fokus ili klik na statistiku otvara osnovu i izvor bonusa. Oprema pokazuje probno poredjenje napada.
- Nula poena, zakljucan tier i trajan rang saborca imaju odvojena stanja.

**Proba:** Kreiraj lika, otvori List lika, otvori Maksimalni HP i klikni Radana. Proveri izvor bonusa, prikaz 0 poena i trajan rang.

Chromium/Qt na Linuxu: 17/17 na 1280x800. Offline demonstracija sa probnim podacima.
