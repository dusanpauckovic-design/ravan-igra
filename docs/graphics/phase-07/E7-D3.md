# E7-D3 · Otisak i studija energije

Graficka baza E6 `ab59e0305f74a0ee599d34d2b4c4cb60124f4edf`. Igriva baza E7-P5 `2bab365d22d06120d47016f635a9081143914ca4`. Grana `graphics/e7-combat`.

Potvrdjeno postavljanje Otiska i okidanje citaju semanticki ID. U igri ostaje diskretan prsten u jednoj zoni, a HP broj dolazi iz receipta. Odvojena art studija prikazuje belu, sivu i crnu na dve podloge, sa iskljucenim kretanjem na pocetku.

## Proba

U E7 kampanji odaberi Otisak i potvrdi prazno polje. U odvojenom pregledu ukljuci animaciju.

## Provera

Qt i Node proveravaju jedan event, snapshot, prolaz, trajanje i gate. Sivi ton je radna paleta Otiska; kanonska klasifikacija sposobnosti nije dodeljena. Qt kadrovi koriste pripremljene scene stvarne igre.

```sh
(cd /path/to/E7-P5 && python build.py)
python graphics/phase07/build.py /path/to/E7-P5 Ravan_E7-D3.html --through 3
```
