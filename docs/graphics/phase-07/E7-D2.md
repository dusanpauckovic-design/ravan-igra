Graficka baza E6 `ab59e0305f74a0ee599d34d2b4c4cb60124f4edf`. Igriva baza E7-P5 `2bab365d22d06120d47016f635a9081143914ca4`. Grana `graphics/e7-combat`.

Stabilan stav i nalet imaju razlicitu tezinu, nagib i status. Prelaz cita mode event. Opasna zona ostaje iz engine-a; oporavak i udar bez gubitka HP imaju jasne poruke.

## Proba

Uporedi stabilan stav i nalet, pa pomeri metu van oznacene zone.

## Provera

Qt proverava pravi prelaz i istu metu na tabli. P2 Node pokriva stvarni prekid, promasaj i oporavak. Qt kadrovi koriste pripremljene scene stvarne igre.

```sh
(cd /path/to/E7-P5 && python build.py)
python graphics/phase07/build.py /path/to/E7-P5 Ravan_E7-D2.html --through 2
```
