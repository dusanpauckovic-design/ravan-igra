# E7-D5 · Kontakt i zvuk

Graficka baza E6 `ab59e0305f74a0ee599d34d2b4c4cb60124f4edf`. Igriva baza E7-P5 `2bab365d22d06120d47016f635a9081143914ca4`. Grana `graphics/e7-combat`.

2.5D cue cita postojeci ID dogadjaja i koristi postojeci mute/volume. Korak kroz blato, gard, prekid, nalet i Otisak imaju razlicite sinteticke tonove. Potvrda ostaje izvor kontakta i HP-a.

## Proba

U 2.5D ukljuci zvuk u postojecim kontrolama, potvrdi korak, gard ili Otisak, pa iskljuci zvuk.

## Provera

Qt proverava izbor jednog tona po ID-ju. Uporedno merenje meri JS poziv crtanja, bez prikaza frejmova i fizickog preslusavanja. Qt kadrovi koriste pripremljene scene stvarne igre.

```sh
(cd /path/to/E7-P5 && python build.py)
python graphics/phase07/build.py /path/to/E7-P5 Ravan_E7-D5.html --through 5
```
