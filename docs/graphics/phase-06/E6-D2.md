# E6-D2 · Dnevnik i pouzdanost

Baza E6-P5 `236d53f9c5e9d244c6012c8deaa5a5b90e97e02d`. Grana `graphics/e6-world`. Prikaz koristi stvarni gameplay Etape 6.

Glasina nema marker, vidjen orijentir koristi zaseban oblik, potvrdjen dobija znak. Na mapi je najvise jedan svez istorijski otisak. Zapisi imaju poreklo, starost i komandu Proveri kada je dostupna.

## Proba

Raspitaj se u kampu, dodji do obale, klikni znak pa Proveri.

## Provera

Qt provera glasa, markera, poznatog lociranja bez promene sata i stvarne potvrde. P2 Node pokriva 30 seedova. Qt koristi zasebnu kompatibilnu kopiju. Kadrovi koriste pripremljene scene iz igre, sa njenim engine-om i portovima.

## Build

```sh
(cd /path/to/E6-P5 && python build.py)
python graphics/phase06/build.py /path/to/E6-P5 Ravan_E6-D2.html --through 2
```
