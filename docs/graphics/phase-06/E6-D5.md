# E6-D5 · Trajne promene i kamera

Baza E6-P5 `236d53f9c5e9d244c6012c8deaa5a5b90e97e02d`. Grana `graphics/e6-world`. Prikaz koristi stvarni gameplay Etape 6.

Osiguran prelaz i recept imaju zasebne oznake. Mapa pamti pogled po regiji. Dugme Svetlo menja atmosferu prikaza.

## Proba

Uporedi mapu pre/posle pobede i istrazivanja rusevine. Probaj svetlo, nizi kvalitet i centriranje.

## Provera

Qt provera obe posledice i prikaza bez trosenja sata; Node proverava stvarne troskove i reload. Puna zajednicka QA ostaje kod integratora. Qt koristi zasebnu kompatibilnu kopiju. Kadrovi koriste pripremljene scene iz igre, sa njenim engine-om i portovima.

## Build

```sh
(cd /path/to/E6-P5 && python build.py)
python graphics/phase06/build.py /path/to/E6-P5 Ravan_E6-D5.html --through 5
```
