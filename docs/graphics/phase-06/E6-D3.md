# E6-D3 · Grupe i vidokrug

Baza E6-P5 `236d53f9c5e9d244c6012c8deaa5a5b90e97e02d`. Grana `graphics/e6-world`. Prikaz koristi stvarni gameplay Etape 6.

Tri siluete koriste javne grupe porta. Panel prikazuje poznatu nameru i poslednji trenutak vidjenja. Izgubljena grupa vise nema map marker. Kontakt koristi postojece dugme igre.

## Proba

Izaberi vidljivu grupu, zatim promeni vidokrug i uporedi status u detalju.

## Provera

Qt provera odabira i gubitka kontakta iz pripremljenog stanja, Node proverava potere i skretanja. Qt koristi zasebnu kompatibilnu kopiju. Kadrovi koriste pripremljene scene iz igre, sa njenim engine-om i portovima.

## Build

```sh
(cd /path/to/E6-P5 && python build.py)
python graphics/phase06/build.py /path/to/E6-P5 Ravan_E6-D3.html --through 3
```
