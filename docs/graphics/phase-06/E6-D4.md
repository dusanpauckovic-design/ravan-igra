# E6-D4 · Od kontakta do bojista

Baza E6-P5 `236d53f9c5e9d244c6012c8deaa5a5b90e97e02d`. Grana `graphics/e6-world`. Prikaz koristi stvarni gameplay Etape 6.

Pregled kontakta daje teren, smer i zaustavljen put uz stvarne akcije. U 2.5D recna scena ima odsjaj, suma rub cistine, a prevoj kamene ivice. 2D deli isti kontekst i stil boje.

## Proba

Prihvati susret pa prebaci 2D/2.5D. Uporedi uslove na kartici sa zadatkom u borbi.

## Provera

Qt klik prihvatanja i isti kontekst za tri bioma. Kadrovi su iz stvarnih borbi na 1024×640. P4 Node proverava 400 tabli. Qt koristi zasebnu kompatibilnu kopiju. Kadrovi koriste pripremljene scene iz igre, sa njenim engine-om i portovima.

## Build

```sh
(cd /path/to/E6-P5 && python build.py)
python graphics/phase06/build.py /path/to/E6-P5 Ravan_E6-D4.html --through 4
```
